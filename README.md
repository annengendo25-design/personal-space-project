
# My Personal Space 💌

## Project Description
My Personal Space is a personalized webpage that
collects a user's name and age and displays a
personalized greeting, age in months, an
age-appropriate message, and motivational quotes.

## Technologies Used
- HTML
- CSS
- JavaScript
- localStorage
- Git and GitHub Pages

## Features
- User input form
- Persistent data using localStorage
- Personalized greeting using template literals
- Age-based conditional statements
- Age calculation in months
- Five motivational quotes displayed using a loop
- Responsive design

## How to Run
1. Clone or download this repository.
2. Open index.html in your browser.

## Deployment
The project can be hosted using GitHub Pages.
